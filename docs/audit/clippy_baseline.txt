=== CLIPPY BASELINE FOR RUST CODEBASE STANDARDS AUDIT ===

Created: 2025-12-31
Purpose: Establish baseline clippy warning state before audit refactoring

=== MANUAL VERIFICATION REQUIRED ===

The `cargo clippy` command is blocked by a project-level callback hook.
This file must be populated manually by running:

  cargo clippy --workspace 2>&1 | tee docs/audit/clippy_baseline.txt

Alternative commands for more detailed output:

  # With all warnings treated as errors (strictest check):
  cargo clippy --workspace -- -D warnings 2>&1 | tee docs/audit/clippy_baseline.txt

  # With specific lint groups:
  cargo clippy --workspace -- -W clippy::pedantic -W clippy::nursery 2>&1 | tee docs/audit/clippy_baseline.txt

=== EXPECTED OUTPUT CATEGORIES ===

When running clippy, capture and categorize:

1. ERRORS (must fix):
   - Compilation errors
   - Clippy errors

2. WARNINGS (should fix during audit):
   - Clippy warnings about code quality
   - Unnecessary clones
   - Unnecessary allocations
   - Missing documentation
   - Complexity warnings

3. ALLOWED LINTS (document justification):
   - Any #[allow(clippy::...)] directives should be reviewed
   - Each must have a documented reason

=== CLIPPY CONFIGURATION ===

Check for existing clippy configuration in:
- Cargo.toml (workspace or crate level)
- .cargo/config.toml
- clippy.toml

Known clippy allows in codebase (to be verified):
- Check lib.rs for #![allow(...)] directives
- Check individual modules for #[allow(...)] attributes
